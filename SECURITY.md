# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/omegaatt36/ytea/security/advisories/new).
Do not open a public issue.

Include the affected version, steps to reproduce, and the impact you observed.
Reports involving exported browser cookies or other credentials handled by ytea are especially welcome.
